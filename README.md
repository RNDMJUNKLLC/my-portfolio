# William Brandi Portfolio

A responsive resume and portfolio site built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Create a production build with `npm run build`.

## Customize

- Edit content and project details in `src/App.tsx`.
- Edit colors, typography, layout, and responsive behavior in `src/App.css`.
- Replace the placeholder email address and project descriptions before publishing.
